# Logitech G19 LCD Configuration

Custom XML layout for the **Logitech G19 LCD** using **LCDHost**.

> ⚠️ This project is archived and no longer actively maintained.

---

## Overview

This repository contains one of my old custom LCDHost configurations created for the Logitech G19 keyboard.

The goal was to display useful system information directly on the keyboard's built-in 320×240 color LCD while gaming or working.

The layout combines multiple widgets into a single dashboard and makes use of LCDHost plugins and system monitors. The XML targets the Logitech QVGA device (320×240). :contentReference[oaicite:0]{index=0}

---

## Features

The dashboard includes various information panels such as:

- 🕒 Large digital clock
- 📅 Current date
- 🌐 Network traffic monitor
- 💻 CPU usage monitor
- 📊 CPU usage graph
- 📰 RSS news ticker
- 📬 System status information

Some widgets are interactive and respond to the G19 LCD navigation buttons.

## Installation

1. Install LCDHost.
2. Copy `G19.xml` into your LCDHost layouts directory.
3. Open the layout from within LCDHost.
4. Install any missing plugins if prompted.
5. Customize widgets as desired.

---

## Customization

You can easily modify:

- Colors
- Fonts
- Widget positions
- RSS feed URLs
- Refresh intervals
- System monitoring widgets
- Backgrounds
- Text styles

Because everything is stored in XML, the layout can be edited either from LCDHost or manually in a text editor.
